# W0-T06 — Compositor v0

Branch `task/W0-T06-compositor`, off `task/W0-T05-core`.

## What was built

| File | What it is |
| --- | --- |
| `src/engine/compositor.ts` | `composite(target, doc, view)`: the workspace background, Photoshop's transparency grid under the document's visible rectangle, then the pixel layers bottom → top in Normal at opacity × fill. Only the visible part of each layer is drawn; each layer's screen rectangle is rounded exactly like the document's, so layers line up. Nearest-pixel scaling at ≥ 100 %, filtered ("high" quality) below. Groups: their children are drawn with the group's opacity multiplied in (see VERIFY); other layer kinds are skipped until W1. |
| `src/engine/viewport.ts` | `ViewportTarget` gains `checkerboard(rect, anchor)` (a cached 16 × 16 pattern, anchored to the document's corner so it pans with it) and `drawSurface(surface, source, target, opacity, smooth)` (via `drawableOf`, so the canvas stays in the two allowed places). |
| `src/engine/test-pattern.ts` | The `?pattern` stand-in is now a **real `Document`** built with the core's commands (`add_layer`, `fill_layer`, `set_layer_props`, and one `Surface.write`): "Blocks" (250-px blocks over the left two thirds), "Band" (red, 50 % opacity, across the middle and over the transparent third), "Pixels" (64 × 64 noise at the centre). |
| `src/engine/engine.ts` | `?pattern` builds that document and draws it through `composite`. |

## What was tried, and what was seen

Headless Chromium, `npm run dev`, `?pattern` (4000 × 3000, three layers):

- The document opens at 25 %. The right third, where no layer has pixels,
  shows the **grid** (white / light grey squares); the blocks hide it
  everywhere they are. Where the 50 % red band crosses the transparent third,
  the grid shows **through** the band. So the grid appears only where the
  layers are transparent, and in proportion where they are partly so — the
  card's first check.
- **400 %** (zoom field set to 400): the 64 × 64 noise patch is 256 screen
  pixels wide, every image pixel a sharp 4 × 4 square.
- **25 %**: the noise patch is averaged into a smooth teal square (filtered
  scaling).
- Building the document (≈ 130 fill commands on a 4000 × 3000 layer) and the
  first frame: under 1.5 s from page load to screenshot, in a headless browser
  with software rendering; not a measurement of the exit criteria.
- Console: clean. `npm run check`, `npm run build`: clean.

## What changed from the card

- The card lists only `compositor.ts`; the viewport gained the two drawing
  operations because the compositor may not touch a canvas (the Surface rule),
  and the test pattern became a real document so the checks exercise the
  compositor.
- Groups are drawn (children with the group's opacity) though W0 has no
  command that makes one: it costs a few lines and keeps a group from
  disappearing if one appears before W1-T02.

## VERIFY

- Photoshop's default transparency grid: "Light" colours `#ffffff` /
  `#cccccc`, "Medium" squares of 8 **screen** pixels, not scaled by the
  display's ratio.
- Group opacity multiplied into the children (right only for pass-through
  groups of non-overlapping Normal layers); W1-T02 composites groups properly.
- Every blend mode is drawn as Normal until W1-T02.
