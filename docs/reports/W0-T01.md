### The Surface rule (the card's lint rule)

`eslint.config.js` restricts, everywhere under `src/` and `ui/` **except**
`src/core/raster/**` and `src/engine/viewport.ts`:

- the globals `OffscreenCanvas` and `ImageData`;
- the members `getContext`, `getImageData`, `putImageData`,
  `transferToImageBitmap`.

Everything else reaches pixels through the `Surface` interface (W0-T05). The
exception list is exactly the two places `ARCHITECTURE.md` §3 and §7 allow, and
it is written once (`CANVAS_FILES`) so a card that adds a third place has to
say so in the same commit.

The second rule — no DOM in the core — bans `document`, `window`, `self`,
`navigator` and `localStorage` in `src/core/**`, `src/tools/**`,
`src/filters/**` and `src/io/**`, with `src/core/raster/**` excepted (it *is*
the canvas). The canvas rule is repeated in that block on purpose: a later
flat-config block *replaces* a rule, it does not extend it, so leaving it out
would have opened a hole for `src/core/foo.ts`.

## What changed from the card

- **`npm run check` has two parts in this card, three in the next.** The card
  writes `tsc --noEmit` + `eslint .` + `node ui/tools/check-data.mjs`, but
  `ui/tools/check-data.mjs` is copied by W0-T02. The script is
  `typecheck && lint` now and W0-T02 adds the data check in the same commit that
  brings the file it checks. (Otherwise T01 could not pass its own check.)
- **TypeScript 5.9, not 7.** The registry serves `typescript@7.x` (the native
  compiler), but `typescript-eslint@8.70` does not support it yet, and the
  linter is half of `npm run check`. Pinned to `^5.9.3`; moving to 7 is a
  one-line change once the ecosystem follows.
- **`lib` is the interface's, not the worker's.** `DOM` and `WebWorker` cannot
  both be in `lib` (duplicate declarations), so the worker's globals will be
  pulled in per file with `/// <reference lib="webworker" />` in W0-T03. The
  tsconfig says so where the setting is.
- **`.editorconfig` and `package-lock.json` are extra** (the card lists the
  first eight files): the lock file is what makes `npm ci` reproducible, and
  the editor config keeps the copied interface's tabs intact. `.gitattributes`
  was added too, for the reason its row above gives — without it the first
  `git add` printed ten "LF will be replaced by CRLF" warnings.
- **`@types/node` is a dev dependency** for `vite.config.ts` and
  `ui/tools/check-data.mjs`; it is not shipped.
