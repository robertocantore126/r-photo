## W8-T00 — Decisions (Rob)

1. **Layer styles render on the GPU** as effect passes of the compositor:
   - the shadows and glows are blurs of the layer's alpha at the view's scale
     (sizes × the scale);
   - bevels are a height field from a distance transform, lit;
   - Photoshop's order: drop shadow, outer glow, content, the interior
     effects, stroke.

   Fill affects the content only, opacity everything. **Yes.**
2. **Smart Objects**:
   - `kind: "smart"` with an embedded document (a nested `.rph` in the same
     zip, or the PSD kept by W3) or a linked file handle;
   - a transform (affine, perspective or warp);
   - a filter list;
   - rendered from the source's composite at the scale the transform needs,
     so transforms never lose quality.
   **Yes.**
3. **Smart Filters** use W4's filters on the Smart Object's rendered pixels,
   with one filter mask and per-filter blending options. **Yes.**
4. **Artboards**: a top-level group with bounds and a background colour; the
   canvas is the union of the artboards. **Yes.**

## W8-T01 — Layer styles: the ten effects

**Files**
- `src/core/styles.ts`;
- `src/engine/gpu/styles.wgsl`, `styles.ts`;
- `ui/js/native/layer-style.js` (Fotox's dialogs made live).

**What to build**
- The effects:
  - Drop Shadow, Inner Shadow, Outer Glow, Inner Glow;
  - Bevel & Emboss (styles, techniques, depth, direction, size, soften,
    shading with gloss contour; Contour and Texture sub-sections);
  - Satin, Color Overlay, Gradient Overlay, Pattern Overlay, Stroke (size,
    position, fill type).
- Contours, Use Global Light (a document setting), the Styles panel (presets,
  Photoshop's defaults), Copy / Paste / Clear Layer Style.
- The fx row in the Layers panel, with an eye per effect.
- PSD effects (kept since W3) come alive.

**Check**
- Recreate a classic "button" style (bevel, gradient overlay, drop shadow,
  stroke).
- Open a PSD with effects and compare with Photoshop.

## W8-T03 — Smart Objects

**Files**
- `src/core/layers/smart.ts`;
- `src/engine/smart.ts`.

**What to build**
- Convert to Smart Object (one or several layers).
- Free Transform, Warp and Perspective on a Smart Object change its
  transform, never its pixels.
- Rasterize.
- New Smart Object via Copy (an independent copy) versus duplicate (a shared
  source).
- File ▸ Place Embedded and dropped files make Smart Objects from now on (W2
  made pixel layers).
- PSD smart objects (kept since W3) become Smart Objects.

**Check**: scale a photo Smart Object down to 10 % and back: no loss; place
a PSD as a Smart Object.

## W8-T04 — Edit Contents, linked Smart Objects

**Files**
- `src/engine/documents.ts` (a child document tab bound to its parent).

**What to build**
- Edit Contents opens the source in its own tab. Saving it (Ctrl+S) updates
  the parent: one history step there.
- Place Linked (a file handle); Update Modified Content (the browser cannot
  watch a file, so it is a menu item and a check when the document gets the
  focus); Relink; Embed Linked; Replace Contents.

**Check**: a mock-up with a Smart Object label; edit the label's contents
and see the mock-up update.

## W8-T05 — Smart Filters

**Files**
- `src/core/layers/smart.ts` (the filter list);
- `ui/js/native/layers-panel.js` (the Smart Filters rows).

**What to build**
- Any W4 filter applied to a Smart Object becomes a Smart Filter row:
  - an eye, a double-click to edit with the live preview;
  - blending options (mode, opacity);
  - drag to reorder;
  - one filter mask for the stack.
- Filter ▸ Convert for Smart Filters.

**Check**: Gaussian Blur + Add Noise as Smart Filters, masked; edit the blur
radius later; reorder them.
