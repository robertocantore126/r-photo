# W9 — Content-aware tools, deformations and AI

> **Draft, Claude, 26 Sep 2026.** Checks: `npm run check` + the **Check**
> list in the browser (D-003). Decisions in W9-T00 first: the AI half
> depends on models and licences Rob chooses.

Goal:
- the non-AI content-aware family on one PatchMatch engine: Content-Aware
  Fill, Patch and Spot Healing in content-aware mode, Content-Aware Move,
  Content-Aware Scale;
- the deformation workspaces: Liquify, Puppet Warp, Perspective Warp,
  Vanishing Point;
- the AI features, running locally in the browser or through Rob's ComfyUI:
  Select Subject, Remove Background, Sky, the Object Selection tool, a few
  Neural Filters, Generative Fill and Expand.

Exit criteria:
- Content-Aware Fill of a 400 × 300 hole in a 4000 × 3000 photo in ≤ 5 s,
  interface live;
- Liquify's Forward Warp fluid on a 4000² photo;
- Select Subject in ≤ 3 s on WebGPU;
- Generative Fill returns three variations as layers.

Read first:
- `fotox-plan/docs/tasks/M11.md` (PatchMatch, Liquify, Puppet Warp,
  Perspective Warp, Vanishing Point: algorithms and parameters);
- `fotox-plan/docs/tasks/M13.md` (the model candidates, licences, the
  ComfyUI bridge);
- Lossy Layers' `src/segment/*` (a segmentation model already running in a
  worker).

Order: T00 → T01 → T02 … T05 → T06 … T09 → T10 → T11 … T13 → T14.

## W9-T00 — Decisions (Rob)

1. **PatchMatch in TypeScript first** (a job worker, typed arrays,
   multi-scale):
   - if it misses the 5 s target, it moves to WebAssembly compiled from Rust
     (Fotox's toolchain is at hand) or to WebGPU compute;
   - the interface of the job does not change.
   **Yes.**
2. **Inference**:
   - **onnxruntime-web** (MIT) with the WebGPU execution provider and the
     WASM one as fallback;
   - models are downloaded on first use, after a dialog that shows the size,
     into the browser's Cache Storage, and deletable from the preferences.
   **Yes.**
3. **Models** (every licence verified in this card before adoption):

   | Use | Candidate | Licence to verify |
   | --- | --- | --- |
   | Select Subject, Remove Background | BiRefNet | MIT (reported) |
   | Object Selection | SAM 2 / EfficientSAM, or Lossy Layers' model | Apache-2.0 (reported) |
   | Sky | a sky segmentation model | to find |
   | Super Zoom | Real-ESRGAN | BSD-3 (reported) |
   | JPEG Artifacts Removal | FBCNN or similar | to find |

   BRIA RMBG is excluded (non-commercial). **Rob picks.**
4. **Generative Fill and Expand go through Rob's local ComfyUI**:
   - its HTTP API, with Fotox-style bundled inpaint and outpaint workflows;
   - ComfyUI must run with `--enable-cors-header` so the browser may call it;
   - the address is set in the preferences.
   **Yes.**

## W9-T01 — PatchMatch core

**Files**
- `src/jobs/patchmatch/{nnf.ts,vote.ts,pyramid.ts,worker.ts}`.

**What to build**
- `fill(source, holeMask, sampleMask, params)`:
  - patch size 7, random search + propagation;
  - a multi-scale pyramid with EM voting, colour adaptation;
  - seeded;
  - it reads only the region of interest (the hole plus the sampling area).
- Rotation / scale / mirror adaptation as options (for T02).

**Check**: remove a person from a beach photo with a debug action; the fill
is plausible and the same seed gives the same result.

## W9-T05 — Liquify

**Files**
- `src/engine/workspaces/liquify.ts`;
- `src/core/liquify.ts`;
- `ui/js/native/liquify.js`.

**What to build**
- Filter ▸ Liquify:
  - tools: Forward Warp, Reconstruct, Smooth, Twirl, Pucker, Bloat, Push
    Left, Freeze / Thaw Mask, Hand, Zoom;
  - brush size, density, pressure, rate;
  - Reconstruct All, Restore All, Show Mesh / Backdrop, save / load the mesh.
- A displacement field at ¼ resolution. The preview is drawn by the GPU
  from the source texture and the field (fluid at any size); OK applies it
  with the bicubic sampler as a job.
- Face-Aware Liquify is left out (it would need face landmarks).

**Check**: a portrait's smile and a shirt's fold, frozen areas untouched.

## W9-T07 — Perspective Warp

**Files**
- `src/engine/workspaces/perspective-warp.ts`.

**What to build**
- Layout: draw quads on the planes, and adjacent edges snap together.
- Warp: move the corners; automatic straighten (vertical / horizontal).
- The planes are projective mappings continuous across shared edges.

**Check**: change the viewing angle of a building photo.

## W9-T08 — Vanishing Point

## W9-T09 — The inference host

**Files**
- `src/jobs/ai/{session.ts,models.ts,worker.ts}`;
- `ui/js/native/models-prefs.js`.

**What to build**
- Load a model once per session (T00-2).
- The input is read from the composite at a working resolution (e.g. 1024 on
  the long edge). The mask output is upsampled and refined in the edge band
  with W7's guided filter.
- The model manager (download with size and progress, delete) in the
  preferences.
- Without WebGPU, the WASM provider: slower, with a warning.

**Check**: download a model, run it, reload the page: it is not downloaded
again.

## W9-T13 — Generative Fill and Generative Expand (ComfyUI)

**Files**
- `src/engine/comfy.ts`;
- `assets/comfy/{inpaint,outpaint}.json`;
- `ui/js/native/generative.js` (the contextual task bar's prompt).

**What to build**
- With a selection, Generative Fill:
  - sends the area around the selection at the model's resolution, with its
    mask and the prompt, to the bundled workflow;
  - three variations come back, as a generative layer group with the
    selection as its mask (Photoshop's Generative Layer), switchable in
    Properties;
  - one history step.
- Generative Expand: the Crop tool beyond the canvas, then Fill "Generative
  Expand" sends the outpaint workflow.
- Clear errors when ComfyUI is not reachable or CORS is off, with the fix
  shown. Timeouts, never a hang.

**Check**: replace the sky of a photo with a prompt; expand a portrait photo
to landscape.
