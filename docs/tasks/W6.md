# W6 — Retouching and the full brush system

> **Draft, Claude, 26 Sep 2026.** Checks: `npm run check` + the **Check**
> list in the browser (D-003). Needs W2's brush engine. Decisions in W6-T00
> first.

Goal: every retouching and painting tool of Photoshop's toolbox that is not
a selection, vector or content-aware tool, on one extensible brush engine:
- Clone and Pattern Stamp, Healing and Spot Healing, Patch, Red Eye;
- Dodge / Burn / Sponge, Blur / Sharpen / Smudge;
- History and Art History Brush, Color Replacement;
- Background and Magic Eraser, Mixer Brush;
- plus sampled brush tips, the Brush Settings panel, presets, ABR import and
  patterns.

Exit criteria:
- every brush-like tool keeps W2's pen-to-pixel responsiveness at 300 px on a
  4000 × 3000 document;
- a live stroke equals its replay (undo / redo gives the same pixels).

Read first:
- `fotox-plan/docs/tasks/M8.md` (Fotox's plan for the same tools: options,
  formulas, `VERIFY` notes);
- `fotox/crates/fx-ops/src/brush/{stroke,heal}.rs` (clone offsets, the
  healing Poisson blend on a pyramid);
- W2's `src/core/brush/*`.

Order: T00 → T01 → T02 → T03 … T09 (any order) → T10 → T11.

## W6-T00 — Decisions (Rob)

1. **Dab operations** (Fotox M7-T08's "tool kinds", done here in TS). A
   brush tool is:
   - `DabOp { needs: { sourceWindow?: radius, state?: boolean }, pixel(before,
     window, k) }`;
   - or a stateful variant for Smudge and the Mixer Brush.

   The engine keeps spacing, pressure, the stroke buffer, the selection,
   lock transparency and undo. A new tool is one file. **Yes.**
2. **Formulas Photoshop does not publish** (Dodge / Burn ranges, Sponge,
   Smudge strength, Color Replacement, the Mixer Brush) are published
   approximations marked `VERIFY` and compared with Photoshop in W12. **Yes.**
3. **ABR import**: sampled tips and the basic dynamics of ABR v6+; computed
   tips and dual brush / texture later. **Yes.**
4. **The History Brush source** is a History panel state: the source column
   of Photoshop's panel. **Yes.**

## W6-T01 — Brush tips, dynamics, Brush Settings, presets, ABR

**Files**
- `src/core/brush/{tip.ts,dynamics.ts,presets.ts}`;
- `src/io/abr.ts`;
- `ui/js/native/{brush-settings,brushes}-panel.js`.

**What to build**
- Sampled tips (an image, scaled from one master per stroke).
- Shape Dynamics (size / angle / roundness jitter with pressure / tilt /
  fade), Scattering, Transfer, Color Dynamics, Smoothing (three modes).
- The randomness is seeded per stroke, so live = replay.
- The Brush Settings and Brushes panels are live.
- Presets: save / rename / delete, a stroke thumbnail, import `.abr`
  (T00-3), export our JSON.

**Check**: import an ABR of Rob's and paint with three of its tips; jitter
and scatter look like Photoshop's.

## W6-T02 — Clone Stamp, Healing Brush, Spot Healing Brush, Patch

**Files**
- `src/tools/{clone.ts,heal.ts,spot-heal.ts,patch.ts}`;
- `src/core/heal.ts` (Poisson blend on a pyramid, from Fotox D-045).

**What to build**
- Clone Stamp:
  - Alt+click the source;
  - Aligned, Sample (current / current & below / all layers);
  - the source overlay (a crosshair, and the cloned pixels shown under the
    brush outline);
  - the Clone Source panel's offset and flip (basic).
- Healing Brush: the clone, then at pen-up a blend that keeps the source's
  texture and the destination's shading.
- Spot Healing Brush: Proximity Match and Create Texture. Content-Aware
  arrives in W9.
- Patch: draw an area and drag it (Source / Destination, Transparent).
  Content-Aware mode is W9.

**Check**: remove blemishes from a portrait with each tool; clone a pattern
Aligned and non-Aligned.

## W6-T03 — Dodge, Burn, Sponge

**Files**
- `src/tools/tone.ts`.

**What to build**
- Dodge / Burn:
  - Range: Shadows / Midtones / Highlights;
  - Exposure;
  - Protect Tones.
- Sponge: Saturate / Desaturate, Flow, Vibrance.
- On a mask (gray), Dodge / Burn work on the gray and Sponge does nothing.

**Check**: dodge the midtones of a face; sponge-desaturate a background with
Vibrance on.

## W6-T04 — Blur, Sharpen, Smudge

**Files**
- `src/tools/{focus.ts,smudge.ts}`.

**What to build**
- Blur / Sharpen: a source window and a small kernel per dab; Strength; mode;
  Sample All Layers; Protect Detail for Sharpen.
- Smudge: a pickup buffer carried along the path; Strength; Finger Painting
  (starts with the foreground); Sample All Layers.

**Check**: smudge paint strokes; blur a harsh edge; sharpen eyes with
Protect Detail.

## W6-T05 — Patterns, Pattern Stamp, pattern fills

**Files**
- `src/core/pattern.ts`;
- `src/tools/pattern-stamp.ts`;
- `ui/js/native/patterns-panel.js`.

**What to build**
- Edit ▸ Define Pattern (from the selection or the whole image); a Patterns
  panel (library, `.pat` import for the RGB 8-bit patterns, export our
  format).
- Pattern Stamp (Aligned, Impressionist).
- Pattern in Edit ▸ Fill and in the Paint Bucket.
- Layer ▸ New Fill Layer ▸ Pattern (scale, angle, snap to origin): the
  compositor draws it, no pixels.

**Check**: define a pattern from a texture, fill a layer with it, paint it
with the stamp; a pattern fill layer scaled 50 %.

## W6-T06 — History Brush, Art History Brush

**Files**
- `src/tools/history-brush.ts`;
- `ui/js/native/history-panel.js` (the source column).

**What to build**
- The History Brush paints from the chosen history state (the same layer in
  that snapshot). If the layer did not exist then, or the canvas size
  changed, it refuses with Photoshop's message.
- The Art History Brush: stylized strokes sampled from the source state.
  Styles: Tight / Loose Short / Medium / Long, Dab, Tight / Loose Curl; Area,
  Tolerance.

**Check**: blur a photo, then paint the original back on the eyes with the
History Brush.

## W6-T07 — Color Replacement, Red Eye

**Files**
- `src/tools/{color-replace.ts,red-eye.ts}`.

**What to build**
- Color Replacement:
  - Mode: Hue / Saturation / Color / Luminosity;
  - Sampling: continuous / once / background swatch;
  - Limits: contiguous / discontiguous / find edges;
  - Tolerance, Anti-alias.
- Red Eye: a click finds the red blob around it (a flood on redness in a
  radius), desaturates and darkens it (Pupil Size, Darken Amount).

**Check**: turn a red car blue with Color Replacement; fix a red-eye photo.

## W6-T08 — Background Eraser, Magic Eraser

**Files**
- `src/tools/{bg-eraser.ts,magic-eraser.ts}`.

**What to build**
- Background Eraser: sampling (continuous / once / background swatch),
  limits, tolerance, Protect Foreground Color. On the Background layer it
  becomes a layer first.
- Magic Eraser: the wand's flood, made transparent; tolerance, contiguous,
  anti-alias, all layers, opacity.

**Check**: cut a product out of a white background with both tools.

## W6-T09 — Mixer Brush

**Files**
- `src/tools/mixer.ts`.

**What to build**
- Reservoir + pickup buffers; Wet, Load, Mix, Flow; Load / Clean after each
  stroke; Sample All Layers.
- The preset combinations of Photoshop's menu (Dry, Moist, Wet, Very Wet,
  and their Light / Heavy variants).

**Check**: blend two colours on canvas with Very Wet, Heavy Mix; paint a
photo-based study.
