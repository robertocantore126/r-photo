# W2 — Selections, painting, move and transform

> **Draft, Claude, 26 Sep 2026.** Checks: `npm run check` + the **Check**
> list in the browser (D-003). Decisions in W2-T00 first.

Goal: a working day's editing:
- the selection tools and the Select menu;
- Move, Arrange / Align / Distribute;
- the brush engine with pen pressure (Brush, Pencil, Eraser, on pixels and
  on masks);
- Eyedropper, Paint Bucket, Gradient;
- Fill / Stroke, the clipboard, dropping files as layers;
- Free Transform and its submenu, Crop with straighten, Image Size, Canvas
  Size, Image Rotation;
- guides, grid, snapping, the Zoom tool.

Exit criteria:
- a pen stroke at 100 % on a 4000 × 3000 document follows the pen without
  visible lag;
- a Free Transform preview on a 4000² layer stays fluid;
- the marching ants never slow the view.

## W2-T00 — Decisions (Rob)

1. **Selection model**: a gray Surface of coverage (anti-aliased, feathered)
   plus its offset, as in Fotox (D-040). The ants are the 50 % contour,
   traced with marching squares over the visible area only. **Yes.**
2. **Brush engine**: our own, following Fotox M5's model:
   - dabs at a spacing independent of event batching;
   - a stroke buffer with opacity as a ceiling and flow as build-up;
   - the live stroke equals its replay.

   Klecks is the reference for pen input smoothing and performance, not
   copied wholesale (its brushes follow a different model). **Yes.**
3. **Where brush dabs are computed**: in the engine worker, on CPU, into the
   stroke buffer's dirty rects, which are uploaded each frame. WebGPU dabs are
   a later optimisation. **Yes.**
4. **Free Transform resampling**: Canvas2D `drawImage` with
   `setTransform` for affine transforms (bilinear / high-quality smoothing),
   and our own sampler (Fotox's M6-T01 bicubic kernels, ported) for the final
   result and for perspective and warp. **Yes.**

## W2-T01 — The tool framework

**Files**
- `src/tools/{registry.ts,types.ts}`;
- `src/engine/tools.ts`;
- `src/engine/overlay.ts`;
- `ui/js/optionsbar.js`.

**What to build**
- A tool is a file:
  - it declares its parameters (`ParamSpec`, from Lossy Layers);
  - it handles `pointer` and `key` events in document coordinates;
  - it returns commands, a cursor, a status line, an overlay.
- The option bar's values reach the engine as `tool_options` (Fotox's
  message).
- The overlay (ants, handles, rubber bands, brush outline, crosshair) is
  drawn by the compositor after the image, in screen space (Fotox M5-T02's
  tessellated overlay, or Canvas2D on a second `OffscreenCanvas` stacked over
  the WebGPU one).
- The registry maps Fotox's tool ids (`ui/js/data/tools.js`) to
  implementations. An unknown id shows "Planned for W<n>" in the status bar,
  never silence.

**Check**: a debug tool that draws a crosshair under the pointer follows it
at every zoom.

## W2-T02 — Selection core and the Select menu

**Files**
- `src/core/selection.ts`;
- `src/core/commands/select.ts`;
- `src/engine/ants.ts`.

**What to build**
- Commands: `select` (a shape, and a mode: new / add / subtract /
  intersect), `select_all`, `deselect`, `reselect`, `inverse`, `feather`,
  `modify` (border / smooth / expand / contract, with Fotox's distance
  transform), `select_layer_pixels` (Ctrl+click a thumbnail).
- Selection changes are history steps that do not dirty the document
  (Fotox's D-028).
- The ants march (8 Hz), and are recomputed only when the selection or the
  view changes.

**Check**: Select All, Inverse, Feather 20, Expand 10, Ctrl+click a layer's
thumbnail; undo each step.

## W2-T03 — Marquee and Lasso tools

**Files**
- `src/tools/{marquee.ts,lasso.ts}`.

**What to build**
- Rectangular / Elliptical / Single Row / Single Column Marquee:
  - Shift = square (on a new selection) or add;
  - Alt = from the centre, or subtract;
  - Space moves the shape while drawing;
  - Style: Normal / Fixed Ratio / Fixed Size;
  - Feather, Anti-alias.
- Lasso and Polygonal Lasso: Alt switches between them, Backspace removes the
  last point, a double-click or Enter closes the shape.
- Dragging inside a selection with a selection tool moves the outline;
  the arrows nudge it.

**Check**: every modifier combination of Photoshop's marquee; a polygonal
lasso of 20 points, closed with a double-click.

## W2-T05 — Move tool, Arrange, Align, Distribute

**Files**
- `src/tools/move.ts`;
- `src/core/commands/{offset.ts,arrange.ts}`.

**What to build**
- Drag moves the selected layers. While dragging, only their offsets change
  in the rendered state; the drop is one command, "Move".
- Shift constrains, Alt+drag duplicates, Ctrl+drag auto-selects once,
  Auto-Select (Layer / Group), the arrows nudge (bursts merge into one step).
- With a selection, the selected pixels move (lifted and dropped back, one
  step).
- Show Transform Controls starts Free Transform (T10) on a handle drag.
- Layer ▸ Arrange (within the group), Align and Distribute to the selection,
  the canvas or the layers' content bounds; the Move tool's option bar
  buttons send them too.

**Check**: move, duplicate with Alt, align three layers left and distribute
them; move a selection's pixels and undo.

## W2-T06 — Brush engine: Brush, Pencil, Eraser

**Files**
- `src/core/brush/{tip.ts,dabs.ts,stroke.ts}`;
- `src/tools/{brush.ts,pencil.ts,eraser.ts}`.

**What to build**
- Round tip: size, hardness, spacing, angle, roundness; the Pencil is
  aliased.
- Pressure → size / opacity / flow (the option bar's pressure buttons);
  tilt stored for W6.
- Input smoothing (Photoshop's Smoothing percentage).
- The stroke model of T00-2: blend mode, opacity, flow, Airbrush
  build-up.
- Lock transparency, the selection as a limit, painting on the mask when
  the mask thumbnail is the edit target (gray, with the foreground's
  luminance).
- The Eraser: to transparency on layers, to the background colour on the
  Background layer, with Brush / Pencil / Block modes.
- `[` / `]` size, Shift+`[` / `]` hardness, the number keys set opacity.
- A stroke is one command ("Brush Tool"), and its recorded samples replay to
  the same pixels.
- The brush outline cursor is an overlay (T01).

**Check**
- Pen strokes with pressure, and a slow and a fast stroke of the same length
  look evenly spaced.
- Paint on a mask, erase on the Background.
- Undo a stroke.

## W2-T09 — Fill, Stroke, the clipboard, dropped files

**Files**
- `src/core/commands/{fill.ts,clipboard.ts}`;
- `src/engine/clipboard.ts`;
- `ui/js/actions.js`.

**What to build**
- Edit ▸ Fill:
  - foreground, background, colour, black, 50 % grey, white, pattern (W6);
  - mode, opacity, Preserve Transparency;
  - Alt / Ctrl+Backspace.
- Edit ▸ Stroke (width, location, colour, mode).
- Delete clears the selection.
- Copy, Cut, Copy Merged, Paste (centred), Paste in Place, Paste Into /
  Outside (a mask from the selection), and New Layer via Copy / Cut.

    (`navigator.clipboard.read`);
  - a Copy writes a PNG to it.
- Dropping image files onto an open document places them as layers
  (centred, fitted if larger, with a Free Transform box to confirm). With no
  document, a drop opens them.

**Check**
- Copy from another program and paste.
- Copy Merged into a new document (File ▸ New gets the Clipboard size).
- Drop two photos onto a document.

## W2-T10 — Free Transform, Crop, Image and Canvas Size

**Files**
- `src/tools/{transform.ts,crop.ts}`;
- `src/core/{resample.ts,commands/geometry.ts}`.

**What to build**
- Free Transform (Ctrl+T), ported from Fotox M6-T04:
  - its gestures: proportional corners, Shift, Alt about the reference point,
    sides, rotation with 15° steps, Ctrl distort, Ctrl+Shift skew,
    Ctrl+Alt+Shift perspective;
  - Warp (4 × 4 Bézier patch);
  - Edit ▸ Transform ▸ Scale / Rotate / Skew / Distort / Perspective / Warp /
    Rotate 180° / 90° / Flip;
  - the Interpolation option;
  - with a selection, the lifted pixels move and a hole stays.
- The preview is drawn by the compositor from the source texture with the
  mapping (no resampling until Enter). Enter resamples (T00-4), as one command.
- The Crop tool (Fotox M6-T03):
  - a box with handles and a thirds grid, the outside shaded;
  - straighten by rotating the box;
  - Ratio / W / H, Delete Cropped Pixels.
- Image ▸ Crop and Trim.
- Image Size (with Resample and its methods), Canvas Size (anchor, relative),
  Image Rotation (90° / 180° / arbitrary / flip).

**Check**
- Scale, rotate, perspective and warp a photo.
- Transform a selected area.
- Crop with a 10° straighten.
- Image Size to 50 % Bicubic Sharper.
- Canvas Size +200 px anchored top-left.

## W2-T12 — Acceptance

Rob's checklist:
1. Retouch a photo: select the sky with the wand, feather it, make a
   gradient fill layer through it.
2. Paint on a mask with the pen.
3. Place two photos by drag and drop, transform them, align them.
4. Crop and straighten.
5. Export.
